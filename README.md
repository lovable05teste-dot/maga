# maga

Cópia estática do site **+75 Projetos de Chaveiros de Miçanga**.

Origem: https://colecao-chaveiros-micanga.netlify.app/

O `index.html` preserva o conteúdo, os estilos, as imagens embutidas, os carrosséis, o popup, os links de checkout e os scripts de rastreamento da página original.

## Visualizar

Abra `index.html` no navegador, ou execute `python3 -m http.server 8000` nesta pasta.

## Publicar na Vercel

Importe este repositório. O projeto é HTML estático, sem dependências ou etapa de build. A configuração está em `vercel.json`.
